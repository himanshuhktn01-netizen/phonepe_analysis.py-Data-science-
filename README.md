# 📊 PhonePe Pulse Data Analysis

## 📌 Overview

This project analyzes the PhonePe Pulse dataset using Python to uncover transaction trends, user behavior, demographic insights, and state-wise performance across India.

The project demonstrates data cleaning, exploratory data analysis (EDA), visualization, and statistical analysis using real-world financial transaction data.

---

## 🚀 Features

- Data cleaning and preprocessing
- Missing value handling
- State-wise transaction analysis
- District-wise demographic analysis
- Transaction type distribution
- Device brand usage analysis
- Population vs transaction correlation
- Average transaction value analysis
- Registered user analysis
- Interactive plotting functions for selected states

---

## 📈 Analysis Performed

- Total transactions and transaction amount by state
- Top and bottom performing states
- Most common transaction type in each state
- Highest registered mobile brand by state
- Highest population district in every state
- Average Transaction Value (ATV)
- App opens over time
- Population vs registered users ratio
- Correlation between population and transaction volume
- Average transaction volume per registered user
- Device brand usage ratio
- Year-wise transaction trend
- State-wise transaction trend
- District population visualization
